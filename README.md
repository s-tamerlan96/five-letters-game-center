# Game Center · 5 букв

[Открыть мобильный прототип](https://s-tamerlan96.github.io/five-letters-game-center/)

Интерактивное демо: слово дня, календарь, цепочки, локальная таблица, игровые задания, сундуки и партнёрские розыгрыши. Прогресс хранится в браузере.

Первый вход: бесплатное слово → победный экран → первый сундук за 200 стартовых монет → 2 энергии → ещё 1 за вход.

Профиль → «Сценарии roadmap»: повторить первый вход, завершить день соревнования и перейти к следующему дню. Монеты и энергию можно начислять для проверки. Темы и редкие слова по умолчанию отключены; переключатели находятся в профиле.

**Это прототип, не реальная акция.** Задания партнёров подтверждаются кнопкой в демо, соперники смоделированы локально. Покупок, реальных билетов, призов и кэшбэка нет. Названия брендов используются как примеры дизайна.

`index.html` — самостоятельный файл. Можно сохранить его и открыть в браузере. Просмотр вложений в Telegram может не запускать JavaScript: на телефоне открывайте ссылку выше в Safari или Chrome.
